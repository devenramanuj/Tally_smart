📒 ટેલી સ્માર્ટ (Tally Smart)
રોજમેળની એન્ટ્રી બોલીને, લખીને કે ફોટા પરથી નાખો, અને AI (Gemini 2.5 Flash) તેને હિસાબના નિયમ મુજબ જે તે ખાતામાં ઉધાર/જમા કરી દે છે. તૈયાર થયેલી એન્ટ્રી Tally Prime માં સીધી મોકલી શકાય છે અથવા Tally XML તરીકે ડાઉનલોડ કરી શકાય છે.
એક જ HTML ફાઇલની એપ છે. કોઈ સર્વર, ઇન્સ્ટોલેશન કે build ની જરૂર નથી. GitHub Pages પર ચાલે છે.

🚀 શરૂઆત
1. GitHub Pages પર મૂકવું
આ repo માં tally_smart.html ફાઇલ મૂકો (ઇચ્છો તો નામ index.html રાખી શકાય).
Repo ના Settings → Pages માં branch પસંદ કરીને Save કરો.
થોડી વારમાં https://<તમારું-નામ>.github.io/<repo>/ પર એપ ખુલશે.
2. Gemini API ચાવી
Google AI Studio પરથી મફત API ચાવી બનાવો.
એપમાં સેટિંગ ટેબ ખોલો, ચાવી નાખો અને ચાવી સાચવો દબાવો.
⚠️ ચાવી ક્યારેય ફાઇલમાં લખીને repo માં મૂકશો નહીં. એપમાં ચાવી તમારા પોતાના બ્રાઉઝરમાં જ સચવાય છે.
3. પહેલી એન્ટ્રી
એન્ટ્રી ટેબમાં લખો, બોલો કે ફોટો પસંદ કરો.
એન્ટ્રી તૈયાર કરો દબાવો.
આપોઆપ સાચવવું ચાલુ હોય તો એન્ટ્રી સીધી ખાતાવહીમાં જશે અને નીચે બતાવાશે. ખોટી લાગે તો આ બધી એન્ટ્રી પાછી ખેંચો.
આપોઆપ સાચવવું બંધ કરેલું હોય તો તૈયાર એન્ટ્રી તપાસીને બધી એન્ટ્રી સાચવો દબાવો.
🔗 Tally Prime સાથે જોડાણ
Tally Prime માં એક વાર સેટ કરવું
Tally Prime ખોલીને કંપની ખુલ્લી રાખો.
F1 (Help) → Settings → Connectivity → Client/Server configuration માં TallyPrime acts as ને Server અથવા Both કરો.
પોર્ટ 9000 રાખો.
મેનુના નામ Tally ના સંસ્કરણ મુજબ થોડા અલગ હોઈ શકે.
એપમાંથી મોકલવું
સેટિંગ → Tally Prime માં સીધું મોકલવું કાર્ડ ખોલો.
સરનામું ખાલી રાખો (ડિફોલ્ટ http://localhost:9000) અને ઇચ્છો તો કંપનીનું નામ લખો.
બાકી બધી એન્ટ્રી Tally Prime માં મોકલો દબાવો.
Tally માં Day Book ખોલીને એન્ટ્રી તપાસી લો.
મોકલાયેલી એન્ટ્રી પર ✔ Tally માં મોકલાઈ દેખાય છે, અને તે ફરી બે વાર મોકલાતી નથી. નવા ખાતા Tally માં પોતાની મેળે બને છે (જૂથ આખરી હિસાબ ટેબમાં નક્કી કરેલા મુજબ).
⚠️ ધ્યાન રાખવા જેવું
એપ Tally વાળા જ કમ્પ્યુટરમાં ખુલવી જોઈએ. Tally નો સ્થાનિક સર્વર (localhost) ફોનમાંથી પહોંચી શકાતો નથી. ફોનથી એન્ટ્રી કરીને બેકઅપથી કમ્પ્યુટરની એપમાં લાવી શકાય.
Chrome સ્થાનિક નેટવર્કની પરવાનગી માંગે તો Allow કરો.
બ્રાઉઝર Tally નો જવાબ વાંચી શકતું નથી, એટલે ભૂલ થાય તો પણ "મોકલાઈ" દેખાઈ શકે. પહેલી વાર Day Book માં તપાસવું જરૂરી છે.
"નવી એન્ટ્રી સાચવતા જ આપોઆપ મોકલો" ડિફોલ્ટ બંધ છે. ચાલુ કરશો તો "પાછી ખેંચો" ફક્ત એપમાંથી એન્ટ્રી કાઢે છે, Tally માંથી નહીં.
Tally માં ગયા પછી એપમાં સુધારેલી એન્ટ્રી ફરી Tally માં જતી નથી.
Tally XML (મેન્યુઅલ import)
સીધું જોડાણ ન ચાલે તો સેટિંગ → Tally XML માંથી ગુજરાતી નામ અથવા English names પસંદ કરીને XML ડાઉનલોડ કરો, પછી Tally માં Import Data → Vouchers થી લાવો.
Tally ERP 9 ગુજરાતી અક્ષરો બરાબર ન બતાવે તો English વિકલ્પ વાપરો.
Tally Prime માં ગુજરાતી નામ ચાલવા જોઈએ.

💾 ડેટા અને ગોપનીયતા
બધો હિસાબ તમારા બ્રાઉઝરના localStorage માં સચવાય છે. કોઈ સર્વર પર નથી.
રોજમેળનો ફોટો કે લખાણ ફક્ત એન્ટ્રી બનાવવા માટે Google ના Gemini ને મોકલાય છે.
બ્રાઉઝરનો ડેટા સાફ કરતા પહેલા સેટિંગ → બેકઅપ ડાઉનલોડ કરો. જરૂર પડે તો બેકઅપ પાછું લાવો થી પાછું મળશે.
ટેલી સ્માર્ટ અને હિસાબ સાથી (ERP) એપનો ડેટા અલગ સચવાય છે. ફક્ત API ચાવી સહિયારી છે.
⚙️ મર્યાદાઓ
સ્ટોક (માલની બાકી સિલક) ગણાતો નથી, એટલે વેપારમાં નફો અંદાજિત રહે છે.
એક જ ફોટો બે વાર ઉમેરશો તો એન્ટ્રી બે વાર બનશે. ડુપ્લિકેટ પકડવાની સુવિધા નથી.
બોલવાની સુવિધા બ્રાઉઝરના માઇક પર આધારિત છે. ઇન્ટરનેટ અને માઇકની પરવાનગી જોઈએ. Chrome કે Kiwi માં ચાલે છે.
Gemini ની મફત મર્યાદા પૂરી થાય તો થોડી વાર પછી ફરી પ્રયત્ન કરો.
Claude ના Preview ટેબમાં બહારના સર્વરની વિનંતી બ્લોક થાય છે, એટલે ત્યાં "Failed to fetch" આવે. એપ ડાઉનલોડ કરીને કે GitHub Pages પરથી ચલાવો.
